Test the boundary between tabs and profiles

The writer can read its change straight away. This demo handles the writer's update in its button code because a write doesn't send that tab a storage event. The other tab receives an event when the stored value changes. Writing the same value again leaves the event count where it was.

For an automation test, open both tabs in one browser context, then repeat with the observer in a fresh context. Assert the actual status and event count in each. Check the Cloudbrowser guide to isolated browser profiles for the distinction between tabs in one profile and separate browsers.
