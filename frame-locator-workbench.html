Choose the correct frame for a browser action

The main document and both embedded previews contain a button named Show details. Click one and check the confirmation in that same document.

Main document

Main details hidden.

Embedded previews

Scope the action and its confirmation

For the Schedule preview, identify the iframe by its stable ID. Use the frame locator for both the button and the confirmation.

const schedule = page.frameLocator('#schedule-preview');
await schedule.getByRole('button', {
  name: 'Show details',
  exact: true
}).click();
await expect(schedule.getByRole('status'))
  .toHaveText('Schedule details shown.');
