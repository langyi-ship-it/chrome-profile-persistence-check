Check pause, resume, and fork

  1. Open the standalone preview in a disposable test browser. Save source-check-1 and reload. Only the saved marker should remain.
  2. Pause and resume the test browser. Open the same preview URL and look for the saved marker.
  3. Pause the source before forking it in Cloudbrowser. Resume the fork, open the same URL, and check that it inherited source-check-1.
  4. Save fork-check-2 in the fork. Switch back to the source and confirm it still shows source-check-1. With a one-browser concurrency limit, pause the fork before resuming the source.

This checks local storage on this origin. Website login sessions can expire independently. See the Cloudbrowser browser lifecycle documentation for pause, resume, and fork commands.
